Welcome to Your Personal Diary

A private desktop archive that remembers your life and speaks with you out loud. To awaken full memory and voice, two API keys are required — both are free to start.

Setup Helper · gemini-3.8-flash
Step 1
Gemini API Key (Required: conversation, memory, the diary's voice)
  1. Open aistudio.google.com/apikey ↗
  2. Click "Get API key" → "Create API key". Any project name works.
  3. Copy the key (starts with AIza) and paste it into the first field below.
Plain facts about the free tier:
• On the free tier, Google uses conversation contents to improve its models. Adding a payment card in Google Cloud stops this (daily usage costs cents).
• Live voice (the glowing Arc Reactor) does not work on the free tier at all. The notebook and walkie-talkie notes work completely. That is the plan, not a bug.
Step 2
Groq API Key (Optional but recommended: turns speech into text)
  1. Open console.groq.com/keys ↗
  2. Click "Create API Key". 100% free, no credit card required.
  3. Copy the key (starts with gsk_) and paste it into the second field below.
Why Groq matters:
Without it, the diary still hears you, but your spoken words appear as a placeholder (spoken) instead of text, and the diary searches its memory blindly.
